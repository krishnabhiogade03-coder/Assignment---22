# Heart Disease Prediction

## Project Description
This project predicts whether a patient is likely to have heart disease using a Machine Learning model. The application is built using Python and Streamlit.

## Features
- Predicts heart disease risk
- Simple and user-friendly interface
- Machine Learning model
- Deployed on Streamlit Cloud

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## Files
- app.py
- model.py
- heart_model.pkl
- scaler.pkl
- columns.pkl
- requirements.txt
- heart.csv

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
